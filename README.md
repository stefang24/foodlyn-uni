# Foodlyn

Foodlyn је веб платформа за вођење ресторана и самостално наручивање преко QR кодова. Гост скенира QR код са свог стола, прегледа мени, поручује и плаћа директно са телефона. Поруџбина затим у реалном времену пролази кроз касира, кухињу и конобара, док менаџери и администратор платформе воде рад у позадини.

Пројекат је рађен као завршни рад на Природно-математичком факултету Универзитета у Крагујевцу (Софтверско инжењерство).

## Могућности

### Гост
* Сесије за столом преко QR кода, уз проверу локације (Хаверсинова формула, подесив полупречник)
* Заједничке (гост) или приватне (пријављен корисник) сесије по столу
* Лоби стола који у реалном времену усклађује све уређаје који скенирају исти QR
* Преглед менија са претрагом, категоријама, сликама, додацима и ознакама исхране
* Заједничка корпа за све уређаје за истим столом
* Плаћање картицом на мрежи и готовином уз потврду касира
* Праћење поруџбине уживо, са одбројавањем и звучним обавештењима
* Позив конобару једним додиром

### Особље
* Касирски панел за потврђивање, одбијање и наплату поруџбина
* Кухињски екран са уносом времена припреме и одбројавањем уживо
* Конобарски панел са приказима: послужено, у припреми, столови и позиви са столова
* Статусни екран за госте у ресторану
* Исти ток поруџбина у реалном времену за све улоге, кроз SignalR групе

### Управљање
* Менаџерска контролна табла са прометом, најпродаванијим јелима и показатељима уживо
* Потпуни уређивач менија (менији, категорије, ставке, групе додатака, додаци)
* Уређивач столова са генерисањем QR кодова
* Уређивач радног времена по данима у недељи
* Управљање особљем у оквиру додељених ресторана

### Администрација платформе (SuperAdmin)
* Контролна табла над свим ресторанима
* Управљање валутама, са курсевима у односу на евро
* Преглед системских логова, са грешкама са сервера и из прегледача
* Замена QR токена стола
* Аналитика кроз више ресторана

### Заједнички слојеви
* JWT у HttpOnly колачићима, са SameSite Strict и Secure заставицама
* Ротација refresh токена, са поништавањем при употреби
* Верификација е-поште хешованим шестоцифреним кодовима, уз паузу пре поновног слања
* Лозинке хешоване BCrypt алгоритмом
* Ауторизација по улогама, са хијерархијским политикама
* Вишезакупачки филтер упита на нивоу EF Core-а
* Обрада грешака и на серверу и у прегледачу, уписана у једну табелу логова
* Отпремање слика у локално складиште, са прочишћеним путањама и ограничењем величине
* Подршка за више валута и временских зона

## Технологије

### Backend
* .NET 10, ASP.NET Core Web API, C# 13
* Entity Framework Core 10 са Npgsql провајдером за PostgreSQL
* SignalR за размену порука у реалном времену
* JWT Bearer аутентикација, са читањем токена из колачића
* MailKit за SMTP
* BCrypt.Net-Next за хеширање лозинки
* Mapster за мапирање DTO објеката
* MediatR (уведен кроз модуле, за будуће команде и упите)
* Swashbuckle за Swagger / OpenAPI

### Frontend
* Angular 21 (самостојеће компоненте, сигнали, лењо учитане руте)
* TypeScript 5.9
* PrimeNG 21 са Aura темом
* RxJS 7
* @microsoft/signalr 10 (једна заједничка веза ка хабу)
* SCSS по компоненти

### База
* PostgreSQL, са code-first EF Core миграцијама које се примењују при покретању

## Архитектура

Backend је организован као модуларни монолит. Сваки модул носи свој домен, апликативне сервисе и EF Core конфигурације:

```
backend/src/
  Foodlyn.API/                  REST контролери, OrderHub, middleware, покретање
  Foodlyn.Persistence/          AppDbContext, миграције, репозиторијуми
  Foodlyn.Shared/               Result<T>, BaseEntity, помоћне класе, константе
  Modules/
    Foodlyn.Modules.Identity/   Корисници, улоге, пријава, refresh токени, е-пошта
    Foodlyn.Modules.Restaurants/Ресторани, столови, радно време
    Foodlyn.Modules.Menus/      Менији, категорије, ставке, додаци
    Foodlyn.Modules.Ordering/   Сесије, корпе, поруџбине, аутомат стања
    Foodlyn.Modules.Notifications/ Трајна обавештења
```

Frontend прати поделу по функционалностима:

```
frontend/src/app/
  core/        Распоред, чувари рута, интерцептори, навигација, стање учитавања
  shared/      REST сервиси, DTO модели, компоненте за вишекратну употребу, цеви
  features/    auth, customer, guest-ordering, cashier-panel, kitchen-display,
               waiter-panel, manager-dashboard, super-admin, public-restaurant,
               status-display, staff-order, profile, home, about, legal, errors
```

Сав саобраћај у реалном времену иде кроз један SignalR хаб на путањи `/hubs/orders`. Имена група прате устаљен облик:

```
order:{orderId}
restaurant:{restaurantId}:{role}
user:{userId}
session:{sessionId}
table:{tableId}
table:{tableId}:orders
```

## Покретање

### Предуслови
* .NET 10 SDK
* Node.js 20+ и npm 11+
* PostgreSQL 15+

### Припрема базе
1. Направите празну PostgreSQL базу под именом `foodlyn-uni`.
2. Подешавања су већ уписана у `backend/src/Foodlyn.API/appsettings.json` - мењајте их само ако се ваша инстанца разликује од подразумеване:
   ```
   Host=localhost;Port=5433;Database=foodlyn-uni;Username=postgres;Password=root
   ```
3. Миграције се примењују саме при првом покретању, тако да базу не морате ручно да припремате. По жељи, учитајте и демо податке:
   ```bash
   psql -h localhost -p 5433 -U postgres -d foodlyn-uni -f sql/seed-stari-mlin.sql
   ```
   Демо подаци уносе ресторан „Стари Млин" са менијем, столовима, особљем и историјом
   поруџбина. Лозинка за свако особље је `password`, а корисничка имена су
   `menadzer.starimlin`, `kasir1.starimlin`, `kuvar1.starimlin`, `konobar1.starimlin`, `fadmin`
   и слична - цео списак је у табели `users` у самој скрипти.

### Backend
```bash
cd backend
dotnet restore
dotnet run --project src/Foodlyn.API
```
API се подиже на `http://localhost:5166`. Swagger UI је у развојном режиму доступан на `http://localhost:5166/swagger`.

### Frontend
```bash
cd frontend
npm install
npm start
```
Апликација се сервира на `http://localhost:4200`.

### Подешавања

`backend/src/Foodlyn.API/appsettings.json` носи најважније поставке:

* `ConnectionStrings.Default` за везу ка PostgreSQL-у
* `Jwt.Secret`, `Jwt.Issuer`, `Jwt.Audience`, `Jwt.AccessTokenMinutes`, `Jwt.RefreshTokenDays`
* `Email.*` за SMTP подешавања верификационих порука
* `Ordering.GeoRadiusMeters` и `Ordering.EnforceGeoFence`

Ништа од овога не морате да мењате да бисте покренули пројекат - подразумеване вредности су већ подешене за рад на локалној машини.

CORS је намерно постављен тако да прихвата свако порекло (`AddCorsPolicy` у `backend/src/Foodlyn.API/Extensions/ServiceInitializer.cs`), а развојни сервер фронтенда прихвата сваки host (`allowedHosts` у `frontend/angular.json`). Захваљујући томе пројекат ради одмах након преузимања, без подешавања - и када се фронтенд подигне на другом порту и када му се приступа са друге машине или телефона у истој мрежи. За постављање на јавни сервер ове две вредности треба сузити на конкретне адресе.

## Улоге

| Улога | Опис |
|------|-------------|
| SuperAdmin | Администратор платформе, над свим ресторанима |
| Manager | Води један или више ресторана |
| Cashier | Потврђује поруџбине и наплаћује |
| Cook | Ради на кухињском екрану |
| Waiter | Служи поруџбине и одговара на позиве са столова |
| StatusDisplay | Наменски екран само за приказ гостима |
| User | Регистрован гост, са историјом поруџбина |
| Guest | Анониман гост, везан за једну сесију стола |

## Животни циклус поруџбине

```
Placed -> Approved -> Preparing -> Ready -> Served -> AwaitingPayment -> Completed
                          \                                \
                           Rejected                         Cancelled
```

Сваки прелаз се пре уписа проверава у односу на тренутно стање, а обавештење преко SignalR-а иде само групама на које се тај корак заиста односи.
